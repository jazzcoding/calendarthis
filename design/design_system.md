# CalendarThis! Design System

## Color Palette

### Primary Colors
- **Primary Blue**: #4285F4 (Google Blue)
- **Secondary Green**: #34A853 (Google Green)
- **Accent Yellow**: #FBBC05 (Google Yellow)
- **Error Red**: #EA4335 (Google Red)

### Neutral Colors
- **Text Primary**: #202124
- **Text Secondary**: #5F6368
- **Background**: #FFFFFF
- **Surface**: #F8F9FA
- **Divider**: #E0E0E0
- **Disabled**: #BDBDBD

## Typography

### Font Family
- **Primary Font**: Roboto (Android), San Francisco (iOS)

### Text Styles
- **Heading 1**: 28sp, Bold, #202124
- **Heading 2**: 24sp, Bold, #202124
- **Heading 3**: 20sp, Medium, #202124
- **Subtitle 1**: 18sp, Medium, #5F6368
- **Subtitle 2**: 16sp, Medium, #5F6368
- **Body 1**: 16sp, Regular, #202124
- **Body 2**: 14sp, Regular, #5F6368
- **Button**: 16sp, Medium, #FFFFFF or #4285F4
- **Caption**: 12sp, Regular, #5F6368

## Spacing

### Standard Spacing
- **Tiny**: 4dp
- **Small**: 8dp
- **Medium**: 16dp
- **Large**: 24dp
- **Extra Large**: 32dp
- **Huge**: 48dp

### Layout Padding
- **Screen Padding**: 16dp
- **Content Padding**: 24dp
- **Card Padding**: 16dp

## Components

### Buttons

#### Primary Button
- Background: #4285F4
- Text: #FFFFFF
- Padding: 16dp horizontal, 12dp vertical
- Border Radius: 8dp
- Text Style: Button

#### Secondary Button
- Background: Transparent
- Text: #4285F4
- Border: 1dp #4285F4
- Padding: 16dp horizontal, 12dp vertical
- Border Radius: 8dp
- Text Style: Button

#### Text Button
- Background: Transparent
- Text: #4285F4
- Padding: 8dp horizontal, 8dp vertical
- Text Style: Button

### Cards
- Background: #FFFFFF
- Border Radius: 12dp
- Elevation: 2dp
- Padding: 16dp
- Border (Optional): 2dp color based on event type

### Input Fields
- Background: #FFFFFF
- Border: 1dp #5F6368
- Border Radius: 8dp
- Padding: 16dp horizontal, 12dp vertical
- Focus Border: 2dp #4285F4
- Error Border: 2dp #EA4335

### Calendar Components
- Day Size: 40dp x 40dp
- Selected Day: Circle with #4285F4 background
- Today: Circle outline with #4285F4
- Event Marker: Small dot with event color

### Navigation
- App Bar Height: 56dp
- Bottom Navigation Height: 56dp
- Drawer Width: 280dp

## Icons
- **Size**: 24dp (standard), 20dp (small), 36dp (large)
- **Color**: #5F6368 (default), #4285F4 (active)

## Illustrations
- **Style**: Flat, minimalist with brand colors
- **Empty State**: Centered illustration with message below
- **Onboarding**: Full-color illustrations with brand elements

## Animations
- **Duration**: 300ms (standard), 150ms (quick)
- **Easing**: Standard curve for most transitions
- **Emphasis**: Slight bounce for important elements

## Accessibility
- **Touch Targets**: Minimum 48dp x 48dp
- **Color Contrast**: WCAG AA compliant (4.5:1 for normal text)
- **Text Size**: Scalable with system settings
